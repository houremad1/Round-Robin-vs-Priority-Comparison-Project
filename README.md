# Round Robin vs Priority Scheduling Simulator

## Overview

This project is a CPU Scheduling Simulator built using Python and CustomTkinter.

The simulator compares:

- Round Robin Scheduling
- Preemptive Priority Scheduling

The system visualizes process execution using dynamic Gantt Charts and calculates scheduling metrics such as:

- Waiting Time
- Turnaround Time
- Response Time
- Completion Time

---

## Features

- Add/Edit/Delete processes
- Round Robin scheduling algorithm
- Preemptive Priority scheduling algorithm
- Dynamic Gantt Chart visualization
- Process statistics table
- Average metrics calculation
- Scrollable timeline visualization
- Modern GUI using CustomTkinter
- Algorithm comparison mode

## Scheduling Algorithms

### Round Robin

- Uses fixed time quantum
- Fair CPU sharing
- Processes execute cyclically

### Preemptive Priority

- Higher-priority processes execute first
- Running process can be interrupted
- Lower priority value = higher priority
